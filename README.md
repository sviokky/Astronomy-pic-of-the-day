# NASA Astronomy Picture of the Day (Streamlit App)

A simple Streamlit app that displays NASA’s Astronomy Picture of the Day (APOD) using the NASA API.

## Features
- Fetches daily NASA image
- Shows title, image, and explanation
- Custom blurred background UI

## Tech Stack
- Python
- Streamlit
- Requests
- NASA APOD API
